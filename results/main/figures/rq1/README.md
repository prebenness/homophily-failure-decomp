# RQ1 continuous-local-homophily figures

The current comparison figures use the 30 ERM runs for each of the seven
models on PubMed, ogbn-arxiv, Roman-empire, Amazon-ratings, and arxiv-year.
They are generated by `scripts/plot_rq1_model_comparison.py`.

The figure partitions continuous local homophily into 10 intervals of width
0.1. For each model, it calculates test accuracy separately for every run and
interval. When a dataset has several fixed splits, seed runs are averaged
within split before the split-level means are averaged. The lower bars show
the shared mean number of test nodes per run on a logarithmic scale.
Split-bootstrap intervals are retained in the accompanying CSV and omitted
from the figure because seven overlapping bands obscure the model curves.
For a review rendering with low-opacity 95% confidence envelopes, pass
`--show-confidence-bands`.

An accuracy point is displayed only when every independent accuracy unit
contains at least one test node. Support bars use the separate, literal rule
that every positive mean test-node count is shown and a zero-support bar is
omitted. The accompanying CSV records both display decisions independently.

The grey region labelled `Tail` is the dataset-specific minority-pattern tail
read directly from the corresponding file under `manifests/datasets/`.

## Single-model diagnostic

`scripts/plot_rq1_continuous_homophily.py` supplies the shared calculations and
can also generate the earlier single-model accuracy and margin diagnostic. For
the margin figure, logits are converted to softmax probabilities. The
true-class margin for node `v` is
`p(y_v) - max_{c != y_v} p(c)`. A node appearing in several test splits or
training seeds is represented once, using its mean margin over all runs in
which it is a test node. The lower bars count all unique plotted nodes in each
interval. The scatter layer is rasterised in the PDF; its axes and labels
remain vector graphics.

The accompanying CSV files contain the calculated values. Each analysis
manifest records the exact run identifiers, raw-file checksums, calculation
settings, software versions, and analysis-script checksums.

Regenerate the five per-dataset figures with:

```powershell
$datasets = "pubmed", "ogbn-arxiv", "roman-empire", "amazon-ratings", "arxiv-year"
foreach ($dataset in $datasets) {
  python scripts/plot_rq1_model_comparison.py `
    --raw-root C:\path\to\heterophilic-graph-paper `
    --dataset $dataset `
    --bins 10
}
```

## Composite paper figure

`scripts/plot_rq1_composite.py` places PubMed and ogbn-arxiv in the top row,
reserves the top-right cell for the shared model and plot-element keys, and
places Roman-empire, Amazon-ratings, and arxiv-year in the bottom row. It uses
12 bins, 95% confidence bands, and logarithmic support panels by default. The
paper uses the macro-F1 variant in the main RQ1 results section and the
accuracy variant in the RQ1 appendix. The PDF is rendered
on a 5.5 by 3.35 inch canvas, matching the paper's text width, with no text
smaller than 8 points before mathematical subscripting. Support axes use a
lower display floor of one mean test node per run, so sub-unit and zero-support
bins have no visible bar.

```powershell
python scripts/plot_rq1_composite.py `
  --raw-root C:\path\to\heterophilic-graph-paper `
  --bins 12
```

Pass `--metric macro-f1` to generate the corresponding macro-F1 figure without
overwriting the accuracy figure. Macro-F1 is calculated separately for each run
and bin over the classes present in that bin's true labels, fixed before the
predictions are evaluated, with `zero_division=0`. The subsequent split-aware
averaging and bootstrap procedure is the same as for accuracy.

```powershell
python scripts/plot_rq1_composite.py `
  --raw-root C:\path\to\heterophilic-graph-paper `
  --bins 12 `
  --metric macro-f1
```
