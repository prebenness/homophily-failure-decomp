# Paper artefacts

This directory contains publication-ready figures and generated table
fragments.

`artifacts.json` maps 23 figures and 25 data-derived tables to their generators
and outputs. LaTeX table fragments are under `generated/`. Figure files are
under `figures/`.

Run the complete analysis with:

```powershell
python scripts/analyse_results.py
```

The quantitative PubMed–GCN panel in Figure 1 is generated by
`scripts/plot_rq5_pubmed_gcn_recovery_panel.py`.
