# Paper artefacts

This directory contains publication-ready figures and generated table
fragments.

`artifacts.json` maps 28 figures and 27 data-derived tables to their generators
and outputs. LaTeX table fragments are under `generated/`. Figure files are
under `figures/`.

Run the complete analysis with:

```powershell
python scripts/analyse_results.py
```

The quantitative PubMed–GCN panel in Figure 1 is generated by
`scripts/plot_rq5_pubmed_gcn_recovery_panel.py`.

The four reverse-intervention PDFs are published reference copies. Their
accepted compact numerical summaries are not available in this checkout.
Fresh reverse inference followed by `analyze_reverse_edge_dose_response.py`
creates those summaries and regenerates the figures; see
`docs/reverse-edge-inference.md`. The compact-only workflow reports when it
retains these references instead of regenerating them.

To check that this inventory covers the current manuscript, supply its local
source directory (the checker does not modify or compile it):

```sh
python scripts/verify_paper_artifacts.py --manuscript-root PATH_TO_MANUSCRIPT
```

Ordinary verification checks completeness and current generated/release
consistency without requiring a rerun to reproduce historical PDF bytes.
`--verify-reference-hashes` is an optional check of the stored reference PDFs.
